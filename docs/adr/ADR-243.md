# ADR-243 — Criterion-level rating backfill for locked annual-review stages

Status: Accepted (2026-08-03) · POLICY §AR-CRITERION-BACKFILL

## Context
ADR-172's `trg_ar_stage_score_required` only asserts that a locked stage carries
*some* criteria score, so a stage could lock with individual criteria missing.
The blast-radius audit found 139 missing criterion ratings across 103 completed
instances. Because `annual_review_compute_final_summary` skips criteria absent
from the terminal stage's `criteria_scores`, each gap silently deducted points.

## Decision
1. Audit table `public.annual_review_criteria_backfill_2026_08` — one row per
   corrected criterion with old/new score, value source, old/new response
   `weighted_score`, old/new instance `total_score` / `final_rating`, reason and
   actor. Admin-read only, RLS enabled.
2. `SECURITY DEFINER` RPC `admin_backfill_annual_review_criteria(p_rows, p_reason)`:
   - admin-only, reason ≥ 10 chars;
   - never overwrites an existing score (skips with `already scored`);
   - merges the score into `criteria_scores`, recomputes the response
     `weighted_score` as Σ(weight × score);
   - recomputes each touched instance once through
     `annual_review_compute_final_summary` (the single sanctioned writer,
     ADR-187 / ADR-235);
   - bypasses the stage-score guard for the duration of the repair only.
3. Resolution rule for the 2026 repair: a rating supplied in the approved sheet
   wins; a blank HOD slot inherits the employee's Self rating
   (`value_source = 'inherited_self'`).

## Result (2026-08-03 run)
139 ratings applied (76 from the sheet, 63 inherited) over 103 instances.
22 instances changed rating band; mean final-score gain +2.19, max +10.00.
5 real instances remain with missing **self**-stage criteria (no upstream value
to inherit) plus 1 excluded test record — these need a send-back, not a backfill.

## Consequences
- Every corrected rating is reconstructable and reversible from the audit table.
- ADR-242 (hardening the trigger to require 100 % stage completion) remains the
  preventive fix; this ADR is the corrective one.
