# ADR-277 — Performance Console layout polish

- **Status:** Accepted
- **Date:** 16 August 2026
- **Related:** ADR-259, ADR-264, ADR-268, ADR-271

## Context
The console read as a wireframe: a bare filter row on the page background, an
unsurfaced header, a category strip that clipped mid-word, and metric values
that drifted per row because each row repeated its own tiny label.

## Decision
Presentation-only pass, no data or logic change:
- Header + tab strip live on one bordered card surface.
- `ScopeToolbar` sits on a `bg-card` bar with a per-filter uppercase label and a
  tooltipped refresh icon button.
- Category strip gains edge fade masks, snap scrolling and tonal count pills.
- `ConsoleMetricRow` gains fixed 92px metric columns, right-aligned tabular
  numerals, a left accent bar on hover/selection and a 56px min height;
  `ConsoleMetricHeader` renders the shared column rail so labels are stated once.
- Pre-load and no-result states are proper empty states; loading skeletons match
  final row height.

## Consequences
- No change to `useBuConsole`, RPC signatures, cascading filter rules (ADR-229),
  virtualization thresholds (ADR-264) or dirty-scope behaviour (ADR-271).
- Regression guard: `src/components/admin/bu-console/consoleLayout.test.tsx`.

## Rollback
Revert the four touched presentation files; no migration involved.
