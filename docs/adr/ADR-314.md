# ADR-314 — Duplicate KPI merge queue viewport fit

Status: Accepted (2026-08-25)

## Context
The ADR-313 duplicate KPI workbench grouped 100+ merge candidates into one modal, but the
dialog was capped at 1180px and the rows relied on truncation. Long KPI titles with appended
description/formula/scoring text pressured the layout and produced a horizontal scrollbar.

## Decision
Presentation-only fix:

1. Enlarge the Performance Console KPI library dialog to a contained `96vw` work surface capped
   at 1400px and 92vh.
2. Keep the dialog header fixed and make only the body scroll vertically.
3. Add `min-w-0`, wrap-safe grid rows and wrapped action/tab rails inside `MergeProposalsTab`.
4. Render long KRA/KPI names as wrapped text instead of truncation-only one-line content.

## Consequences
- Admins can review high-volume duplicate groups without left-right scrolling.
- No data loading, proposal grouping, approval RPC, scoring, RLS, backup or historical KPI data
  changes.
- Regression guard: `src/components/admin/bu-console/consoleLayout.test.tsx`.

## Rollback
Revert the two presentation files and this ADR; no database rollback is required.
