# ADR-313 — KPI bulk de-duplication

Status: Accepted (2026-08-25)

## Context
A single review month held 2,531 KPI rows across only 966 distinct names. The observed
"three identical KPIs" case is one metric whose title carries its description and
scoring ladder. The merge queue reviewed one pair at a time, which does not scale.

## Decision
1. Normalise titles for grouping with `coreTitle` (strips description/formula/scoring
   tails, month brackets, incentive notes) — the same cleaning the console look-alike
   detector uses.
2. Group pending proposals by `(category, cleaned KRA, cleaned KPI)`; classify a group
   `safe` when every variant collapses to the same cleaned title, else `judgement`.
3. Add `public.bu_console_decide_merge_proposals(p_ids, p_approve, p_note)` —
   admin-only, per-proposal audit, already-decided rows skipped.
4. Warn at creation time when a cleaned title already exists in the loaded scope.

## Consequences
- Hundreds of variants clear in a few actions; judgement cases stay explicit.
- No historical score, weightage or locked period is modified by a decision.
- Rollback: the bulk RPC can be dropped; per-pair decisions remain available.
