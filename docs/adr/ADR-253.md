# ADR-253 — TNI Report: KPI weightage column and per-month score columns

## Status
Accepted — 2026-08-11

## Context
The TNI Report exposed continuity evidence as one concatenated text cell
("Apr 2026: 2.80, May 2026: 2.40, …"), which is unreadable and un-sortable, and
it did not show the KPI's weightage, so reviewers could not judge the materiality
of a gap.

## Decision
- Add a **Wt %** column immediately after KPI/Category, sourced from
  `kpis.weightage` (embedded in the `training_needs` select).
- Replace the `Months ≤ Threshold` text column with **one column per month of the
  active filter range**, each showing that month's achieved score to two decimals
  (`—` when unscored, destructive colour at/below the threshold).
- Mirror both in the Excel Detail sheet with explicit header ordering (ADR-236).
- Shared helpers `monthColumnLabel` / `scoreForMonth` keep UI and export in lockstep.

## Consequences
Presentation-only: no schema, RLS, RPC or qualification-logic change. The report
scrolls horizontally for ranges up to 12 months. Rollback = revert the component,
hook and helper edits.
