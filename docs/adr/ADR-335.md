# ADR-335 — Data entry owners can be mapped from the Admin KPI forms

**Date:** 2026-09-01 · **Status:** Accepted · **Policy:** §KPI-SCOPE-SINGLE-VOCABULARY

## Context

Organization-level KPIs are filled centrally by designated **data entry owners**
(`org_kpi_data_owners`, ADR-322). Until now the picker existed only in the
Performance Console group definition editor (`GroupDataOwnersField`). The Admin
KPI Editor and the "Assign New KRA" dialog could mark a KPI organization-level
but not say who owns its value, so freshly created org KPIs were admin-only
until someone re-opened them from the console.

## Decision

1. Extract the picker into `src/components/admin/org-kpi/OrgKpiDataOwnersField.tsx`.
   `GroupDataOwnersField` becomes a thin wrapper — one implementation, no fork.
2. The field supports two modes:
   - `immediate` — the KPI exists; picks write straight to `org_kpi_data_owners`
     (Performance Console, Admin KPI Editor).
   - `pending` — the KPI does not exist yet and its composed `kpi_name` can
     still change; picks are held by the parent and flushed after a successful
     create (Assign New KRA).
3. Pure model in `ownerAssignmentModel.ts`: key readiness, dedupe/remove,
   assignment payload building, flush partitioning, rename-carry decision.
4. A failed owner attachment never rolls the KPI back. Failures stay in the
   form and are named in a toast so the admin can retry.
5. Renaming the KRA/KPI in the editor moves the existing owner rows to the new
   name (ownership is keyed by name), otherwise ownership is silently orphaned.
6. Turning the organization-level toggle off hides the control but deletes
   nothing.

## Consequences

- No schema change, no new RPC; existing RLS on `org_kpi_data_owners` applies.
- Admins can complete the whole org-KPI setup in one screen.
- Regression: `src/components/admin/org-kpi/ownerAssignmentModel.test.ts` (12 tests).

## Rollback

Additive UI plus one optional `disabled` prop on `ManagerCombobox`. Removing the
field restores prior behaviour; the console wrapper keeps working.
