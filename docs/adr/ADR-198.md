# ADR-198 — Department-scoped terminal reviewer override (EHS-Health)

Date: 2026-07-28
Status: Accepted

## Context

HR requested that the **EHS-Health** department's Annual Review chain end at the
Department Head. The previous BU Head left the organisation and the incoming BU
Head — **Amit Kumar Sharma (102050)** — has no context on the cohort's
achievements. The mapped Department Head is **Firoz Ahmad (100801)**, who is the
intended final reviewer.

Audit of the 12 active instances in EHS-Health found:

- 9 instances still carried `bu_head` in `enabled_stages` with `bu_head_id`
  pointing at Amit Kumar Sharma.
- 101248 (Vikram Rajwar) was parked at `pending_bu` even though the dept head
  had already submitted a complete 10/10 response.
- 200449 (Abhishek Raj) was `completed` on a dept-head response with only
  **2 of 10** criteria scored → `total_score` 31 / rating "Poor" (an artefact,
  not a judgement).
- 101959 (Lekh Raj) is legitimately narrative-only (template assigns zero
  scoreable criteria to `dept_head`, per ADR-197) but still awaits submission.
- 8 further instances hold empty dept-head drafts awaiting Firoz's scoring.

## Decision (POLICY §AR-DEPT-TERMINAL-OVERRIDE)

1. EHS-Health instances run `self → dept_head`; `bu_head` is removed from
   `enabled_stages` and `bu_head_id` is nulled.
2. Every affected instance is flagged `has_admin_workflow_override = true`.
3. Head-cascade triggers MUST skip instances carrying that flag, so a future
   `business_units.head_user_id` edit cannot re-add the stage or re-stamp the
   reviewer.
4. A completion that lacks ratings for all scoreable criteria at the terminal
   stage is a defect and is re-opened for the responsible reviewer — the score
   is never synthesised.

## Implementation

- Data repair (audited into `annual_review_bu_removal_repair_2026_07`):
  - 9 instances contracted to `[self, dept_head]`, `bu_head_id = NULL`,
    `has_admin_workflow_override = true`.
  - 101248 advanced `pending_bu` → `completed`; aggregates recomputed with
    `annual_review_compute_final_summary` (82.00 / "Good", scale invariant per
    ADR-187).
  - 200449 re-opened to `pending_dept`; dept-head response unlocked with the
    2 existing scores preserved; `total_score`, `criteria_weighted_score`,
    `final_rating`, `finalized_at`, `finalized_by` cleared.
- Triggers hardened: `tg_cascade_bu_head_change` and
  `tg_business_units_cascade_head_to_ar` now exclude instances where
  `has_admin_workflow_override` is true.
- Existing `trg_ar_stage_score_required` (ADR-172) continues to block any new
  submission that leaves scoreable criteria unscored.
