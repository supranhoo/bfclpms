# ADR-268 — BU Performance Console: compact, review-first layout

## Status
Accepted — 2026-08-15

## Context
The Console tab spent the entire first viewport on a Scope card (four stacked
comboboxes plus a Load button) and then rendered categories as a wrapped chip
grid. Users reported the surface as "space consuming and not user friendly":
scanning KRAs required scrolling past controls that are used once per session.

## Decision
Presentation-only redesign:

1. Scope collapses into a sticky one-line toolbar (`ScopeToolbar.tsx`); below
   `md` the filters live behind a "Filters (n)" sheet.
2. Categories become a horizontally scrollable tab strip with count pills.
3. KRA and KPI lists share a dense row primitive (`ConsoleMetricRow.tsx`) with
   an index chip, title + sub-line, and labelled metric columns.
4. The page header condenses and a breadcrumb shows the active drill path.

Cascading filter logic (ADR-229), the `bu_console_*` RPCs, virtualization
(ADR-264) and all scoring paths are untouched.

## Consequences
- ~2 viewport-thirds of vertical space returned to the KRA list.
- Only measured values are shown; missing metrics render "—".
- Guarded by `src/test/buConsoleLayout.test.tsx`.
