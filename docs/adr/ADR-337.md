# ADR-337 — Performance Console group edit: span contiguity and definition-first matching

Status: Accepted (2026-09-01)

## Context
A group definition edit anchored on July 2026 did not propagate to August 2026
and later. `bu_console_edit_runs` showed July with 1 affected row and September
/ October with 0.

## Root causes
1. `resolveEditSpan` filtered implicit months that were already in the past, so
   the span jumped from the July anchor to the current month, punching a hole.
2. `bu_console_group_edit_definition` matched only on the normalised title key.
   Rollover-created rows had `kpi_title IS NULL`, so they normalised to the
   legacy `kpi_name` and never matched.
3. `batch_insert_kpis_with_rollover_flag` and `buildNewKpi` omitted the
   structured definition fields, which is how those NULLs appeared.
4. The per-month preview rendered a zero-match month as "no KPI assignments",
   indistinguishable from a legitimately empty month.

## Decision
- Spans are contiguous from the anchor; nothing between the anchor and today is
  dropped, nothing before the anchor is touched.
- The RPC accepts `p_definition_id` and matches on `kpi_definition_id` first.
- Rollover carries the structured definition fields.
- The dialog labels back-dated months and highlights zero-match months.
- Existing rows repaired, with previous values archived in
  `public.kpi_title_backfill_2026_09`.

## Consequences
Back-dated group edits now write the whole span. Reversal is per-month
(existing undo runs) plus the archive table for the title repair.
