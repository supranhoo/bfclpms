# ADR-197: Narrative-only vs unscored reviewer stages

- Status: Accepted (July 2026)

## Context
Dept-head stages showed blank scores despite a completed "Overall Recommendation" (e.g. employee 101279).
The ADR-172 sweep (`annual_review_empty_stage_repair_2026_07`, 2026-07-27) rewound locked responses whose
`criteria_scores` were `{}`. That sweep was right for templates that assign criteria to the stage and wrong
for templates that assign none — both rendered as "—", so HR could not tell a defect from a correct blank.

## Decision
1. Classification SSOT: `annual_review_stage_scoreable_criteria_count()` (server) and
   `stageScoreableCriteriaCount()` (client) decide `narrative_only` vs `unscored`.
2. New read-only RPC `annual_review_unscored_stage_diagnostic(p_cycle_id)` (admin/hr_pms) exposes the cohorts.
3. `resolveStageDisplayRating` returns `source: 'narrative'` for submitted zero-criteria stages; the admin grid
   renders "Narrative".
4. New admin tab **Unscored Stages** surfaces the defective cohort for re-scoring. No automated repair: scores
   are reviewer judgement and must not be back-filled.
5. Recurrence is already blocked by `trg_ar_stage_score_required` (INSERT + UPDATE).

## Consequences
Historical `unscored` rows clear only when the reviewer re-scores. Generalised as
POLICY §AR-STAGE-SUBMIT-SCORE-COMPLETENESS. Regression: `src/lib/annualReview/narrativeStageDisplay.test.ts`.
