# ADR-084 — Reviewer Draft Hydration Invariant (POLICY §107)

- Status: Accepted
- Date: 2026-06-10
- Trigger: BUG-AUD-103 — Auditor saved `auditor_achieved_value=103, auditor_score=0` on a Lower-is-Better KPI; on reopen the picker silently displayed the employee's `achieved_value=99` and auto-calc score `4`.

## Decision

1. Reviewer-draft hydration is centralised in `src/lib/reviewerDraftHydration.ts` (`hydrateReviewerDraft`). All scorecards (`UnifiedScorecard`, legacy `AuditScorecard`, future stages) MUST use this helper to populate picker state.
2. When a reviewer draft exists (any of `<prefix>_{score,rating,remarks,achieved_value,evidence_url(s)}` populated, with `0` and `''` treated as data), the picker displays the reviewer's saved values verbatim and NEVER falls back to `existing.achieved_value` (employee's submission).
3. `AchievedValueScoreInput` no longer auto-overwrites a non-null score on mount or on a stale prop re-render. Threshold auto-calc only fires when the reviewer explicitly edits the achieved-value input, or when `score === null`.
4. `UnifiedScorecard` memoizes `kpiIds` so the `useReviewSubmissions` queryKey is stable across renders. Previously, the new-array-per-render churn caused `submissionMap` to race sheet-open hydration.

## Out of scope

- No schema changes. No save-path changes (writes were already correct).
- No changes to `KpiJourneySection` or `carriedScoreResolver` (read-path display in tiles was already correct).

## Verification

- `src/test/reviewerDraftHydration.test.ts` — 26 tests covering numeric/qualitative, all 6 stages, Postgres-numeric-as-string, evidence URL precedence, and the explicit BUG-AUD-103 regression case.
- Manual: auditor saves 103/0 on a Lower-is-Better KPI → reopens to 103/0.

## Rollback

Pure frontend. Revert the four files (`src/lib/reviewerDraftHydration.ts`, `src/components/review/UnifiedScorecard.tsx`, `src/components/review/AchievedValueScoreInput.tsx`, `src/components/review/AuditScorecard.tsx`) to restore pre-ADR behaviour. No data migration required.
