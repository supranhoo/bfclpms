# ADR-223 — Admin-configurable eligibility exemption criteria

Date: 2026-07-31
Status: Accepted
Related: ADR-221 (eligibility & exemptions), ADR-222 (exemption increment cap)

## Context
ADR-221 hardcoded, in effect, which failed eligibility criteria may be waived: absent
days and LWP yes; disciplinary action and the service / month-completion window never.
HR needs that list to be master data so new criteria can be governed without a release,
while keeping the sensitive rules from being flipped by accident.

## Decision
1. `public.annual_review_eligibility_exemption_policy` is the SSOT. It gains
   `is_protected boolean`, `sort_order integer` and `updated_by uuid`. Disciplinary,
   tenure and month-completion rows are seeded as protected.
2. Matching stays substring-based on the normalised criterion name
   (`ar_eligibility_is_exemptable` in the database, `isExemptable` in
   `src/lib/annualReview/effectiveEligibility.ts`) — no logic change.
3. `validateExemptionPolicy()` is the client-side guard: label required, match key
   required, normalised (lower-case, single-spaced) and unique.
4. Admin surface: **Annual Review → Admin → Settings → Eligibility Exemption Rules**
   (`EligibilityExemptionPolicyCard`). Admin / HR PMS only. Protected rows require an
   explicit unlock before `is_exemptable` can be toggled; deletions go through
   `ConfirmDestructiveDialog`.
5. Every insert / update / delete is written to
   `public.annual_review_eligibility_policy_audit` by `trg_ar_elig_policy_audit`
   (before/after JSONB, actor, timestamp). Read access: Admin / HR PMS / Management.
6. `ExemptionDialog` links to the rules card instead of describing the rules in prose.

## Consequences
- Additive schema; rollback = drop the audit table and the three columns.
- Changing a rule takes effect on the next query (React Query, 5 min stale time) and
  applies to every future exemption decision; existing approved exemptions are untouched.
- Guard: `src/test/annualReview/exemptionPolicy.test.ts` (5 cases). POLICY §AR-ELIGIBILITY-EXEMPTION.
