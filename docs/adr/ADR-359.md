# ADR-359 — Team Reviews default view: everyone who has KRAs

Status: Accepted · 2026-09-04 · Amends ADR-348 / POLICY §129

## Context
ADR-348 made Team Reviews default to "Pending action only" (`badge1 > 0`).
An employee whose KRAs all sit at KRA Set has `badge1 = 0`, so their card
disappeared — reviewers reported a 508-member team rendering four cards.

## Decision
The `queue` URL param takes three values:
- `assigned` (default) — members with at least one KPI for the period, any stage.
- `actionable` — legacy ADR-348 behaviour, kept as an opt-in short worklist.
- `all` — full mapped downline, including members with no KRAs.

`src/lib/review/actionableQueueFilter.ts` is the SSOT: `hasAssignedKras`
(`total > 0`) and `isActionableForReviewer` (`badge1 > 0`). `TeamQueueToggle`
became a three-way segmented control with per-mode counts; a dedicated empty
state covers "no KRAs assigned this period".

## Consequences
Presentation only — no schema, RPC, RLS, workflow or scoring change. Existing
`?queue=all` and `?queue=actionable` links keep working. Rollback: set
`DEFAULT_TEAM_QUEUE_FILTER` back to `actionable`.

Tests: `src/tests/actionableQueueFilter.test.ts` (6 cases).
