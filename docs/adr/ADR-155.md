# ADR-155 — Employee RCA card must not mislabel system-scored 0s

- Status: Accepted (July 2026)
- Context: For 100%-system-scored templates (ADR-140), per-stage
  `annual_review_responses` rows are locked with `criteria_scores = {}` and
  `weighted_score = 0`, while `annual_review_instances.total_score` carries
  the real value hydrated from `annual_review_system_scores`. The
  Comprehensive report's Employee RCA card was rendering these 0s through
  `stageRatingFromScore`, which mapped 0 to `"Below Expectations"`, and
  also emitted a separate blank "HOD / Manager" row whenever
  `enabled_stages` contained `dept_head` — even when `dept_head_id ==
  bu_head_id` (dept=BU collapse), producing a duplicate reviewer row for
  the same person. Reported concretely on Ankit Choudhary (101785):
  Self/BU-Head both showed "Below Expectations" and a phantom HOD row
  appeared for Jaspal.
- Decision: presentation-only fix. Add two pure helpers in
  `src/services/annualReview/comprehensiveReport.ts`:
  - `stageRatingDisplay(score, comment)` — returns `'—'` when the score is
    null, or 0 with no comment; otherwise defers to
    `stageRatingFromScore`. An active 0 with a comment still buckets to
    "Below Expectations".
  - `isSystemScoredOnly(row)` — true when Self carries no signal but the
    final `total_score` is > 0.
  Both the RCA card and the Excel exporter route their per-stage Rating
  values through `stageRatingDisplay`. The RCA card additionally
  suppresses the HOD / Manager row when `dept_head_id == bu_head_id` and
  shows a one-line amber banner when `isSystemScoredOnly(row)` is true.
  Export blanks out HOD Score/Rating/Comment on the same collapse.
- Consequences:
  - No RPC, schema, RLS, or reviewer-workflow change. Underlying scores
    and responses are untouched; only their rendering changes.
  - Ankit-shaped rows now display: Self Rating `—`, BU Head Rating `—`,
    no phantom HOD row, and an "System-scored template" banner. Final
    Score 91.72 / Outstanding remain as-is.
  - Reviewers who genuinely enter a 0 (with a comment) still see "Below
    Expectations" — no regression on real low performers.
- Tests: `src/test/comprehensiveReportRcaDisplay.test.ts` covers rating
  suppression, active-zero bucketing, system-scored detection, and the
  dept=BU collapse predicate.
