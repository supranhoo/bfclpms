# ADR-327 — Employee scoring profiles

## Decision

Separate a KPI's shared definition from each employee's scoring contract.

- Shared definition: description and measurement formula.
- Employee scoring profile: target, weightage, R0–R5 bands and scoring test.

Shared-definition standardisation cannot write scoring-profile fields. Scoring rules are reusable assignment templates, not a replacement for the resolved per-employee profile.

## Why

The previous Align workflow classified scoring-test text as wording and offered target flattening. That model could overwrite legitimate employee-specific scoring contracts while appearing to perform a harmless wording cleanup.

## Data and security

No historical score is changed. The descriptive-field backend allowlist is narrowed. The profile reader is authenticated, capability-checked, active-employee-only and server-paged. Existing audited mutations and final-score immutability remain authoritative.

## Rollback

The UI separation can be reverted independently. Restoring scoring logic to the descriptive allowlist is intentionally not part of rollback because it would reintroduce the data-integrity defect.
