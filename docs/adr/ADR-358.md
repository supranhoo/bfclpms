# ADR-358 — KPI-Employee Matrix renders structured (updated) KRA/KPI text

- Status: Accepted
- Date: 2026-09-03
- Related: ADR-269b (KPI text split), ADR-330 (canonical name mode), ADR-351
  (KPI text display SSOT), ADR-065 (matrix scope RPC), POLICY §KPI-TEXT-DISPLAY-SSOT

## Context

`rpc_kpi_employee_matrix_rows` returned only `kra_name`, `kpi_name`, `criteria`,
`weightage` and category, so the report printed the legacy pasted blob even
though the Performance Console had already written `kpi_title`,
`kpi_description`, `kpi_formula` and `kpi_scoring_logic` (populated for 17,496
of 20,378 FY2026 rows). The pivot also keyed on raw `kpi_name`, so legacy name
variants of one KPI appeared as separate rows — the duplicacy users reported.

## Decision

1. Widen `rpc_kpi_employee_matrix_rows` (DROP + CREATE, same argument list) to
   also return the four structured columns. Read-only; filters unchanged.
2. New pure helper `src/lib/reports/kpiMatrixText.ts`:
   `resolveMatrixKpiText` (structured columns → legacy `splitKpiText` →
   raw `kpi_name`; description falls back to `criteria`) and `matrixRowKey`
   (`category | normalized KRA | normalized resolved title`).
3. `useKpiEmployeeMatrix` pivots on `matrixRowKey` and carries
   `kpiTitle`, `description`, `kpiFormula`, `kpiScoringLogic`, plus `rawKpiName`
   for tooltips and the ADR-330 alias lookup. Blocks are enriched from later
   variants when the first contributing row had none.
4. Four new report-registry fields — `kpi_title`, `kpi_description`,
   `kpi_formula`, `kpi_scoring_logic` — renamable/hideable like every other
   column and emitted in the Excel export. The tooltip gains labelled
   Description / Formula / Scoring Logic blocks; the sticky pane is unchanged.

## Consequences

- Structured KPIs read cleanly; legacy rows render exactly as before.
- Row counts drop where variants merge — intended de-duplication. Scores and
  weightages merge per employee exactly as canonical mode already did.
- No schema, RLS, grant, scoring, workflow or write-path change.

## Rollback

Restore the previous RPC body and revert the hook/page/helper; the extra
columns are inert.
