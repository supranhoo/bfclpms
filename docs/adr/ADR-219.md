# ADR-219 — PMS Grade Filter Integration

**Date:** 2026-07-31
**Status:** Accepted
**Author:** Lovable Engineering
**Version:** v2.66.191

## Context

The Bell Curve Analysis tab (ADR-218) and the main Annual Review Report expose filters for Business Unit, Department, Manager, and Division / Location. Users requested a **PMS Grade** filter to narrow distributions and results to a specific grade band, using the master-data grade associated with each employee (`profiles.pms_grade`). The filter must be available in both the Bell Curve tab and the top-level Annual Review Report filter card, but it is a **filter only** — it does not introduce new display columns or rating calculations.

## Decision

1. Extend `public.get_annual_review_comprehensive_report(uuid)` to expose `profiles.pms_grade_id` alongside the existing `grade` column (which already returns `profiles.pms_grade`).
2. Add `pms_grade_id` to the `ComprehensiveRow` TypeScript type and `grade` to the minimal `BellCurveInput` shape so the Bell Curve engine can filter by grade without needing the full row.
3. Add a **PMS Grade** dropdown to the Bell Curve filter row, populated from the in-memory comprehensive report rows.
4. Add a **PMS Grade** dropdown to the main Annual Review Report filter card, populated via the existing `get_distinct_active_pms_grades()` RPC and wired into the existing server-side `pmsGrade` filter on `useAnnualReviewInstancesPaginated`.

## Consequences

- The Bell Curve tab and the main report now share the same master-data grade filter semantics.
- No new schema tables or columns are created; only the comprehensive report RPC return type changes.
- The existing `grade` column in `ComprehensiveRow` remains the canonical display text for PMS Grade.
- Server-side filtering on the main report uses the `pms_grade` text value, consistent with the existing `pmsGrade` argument in `listInstancesPaginated`.

## Implementation

- Database: `supabase/migrations/` — drop and recreate `public.get_annual_review_comprehensive_report` with `pms_grade_id` in the `RETURNS TABLE` clause and the final `SELECT` projection.
- TypeScript:
  - `src/services/annualReview/comprehensiveReport.ts` — add `pms_grade_id: string | null` to `ComprehensiveRow`.
  - `src/lib/annualReview/bellCurve.ts` — add optional `grade` to `BellCurveInput`.
  - `src/components/reports/annual-review/BellCurveTab.tsx` — add `pmsGrade` state, filter logic, and dropdown.
  - `src/pages/reports/AnnualReviewReport.tsx` — add `pmsGrade` state, pass it to the paginated query, add dropdown via `useEmployeeFilterOptions`.
- Tests: update mock `ComprehensiveRow` objects in `comprehensiveReportRca.test.ts`, `comprehensiveReportRcaDisplay.test.ts`, and `monthlyKraSheet.test.ts` to include `pms_grade_id`.
- Documentation: `DOCUMENTATION.md` and `POLICY.md` updated.
