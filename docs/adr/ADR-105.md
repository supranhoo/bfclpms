# ADR-105 — Annual Review team/self detail: remove 2s debounced autosave

Date: 2026-07-02
Status: Accepted

## Context

`useDebouncedResponseDraft` (in `src/hooks/useAnnualReview.ts`) drives the reviewer
draft on both the Team Annual Review detail sheet
(`src/components/annual-review/TeamReviewDetailContent.tsx`) and the employee
self-review page (`src/pages/annual-review/EmployeeAnnualReview.tsx`). It
scheduled a 2-second `setTimeout(persist, 2000)` after every `setDraft` while
the surface also exposed an explicit **Save draft** button that calls `flush()`.

Two writers on the same row + a `useState`-only seed from `initial` (never
re-syncs) produced a reliably reproducible revert:

```
t=0     click 5             → local draft = 5, autosave armed
t=~600  click "Save draft"  → flush persists 5, invalidates `responses`
t=~900  click 4             → local draft = 4, autosave armed
t=~1200 refetch returns {X:5}
t=~scroll — CriteriaScoringMatrix re-render / any remount re-seeds draft from
           the stale server value → picker snaps back to 5, and the pending
           persist(4) never lands because the local state has been replaced.
```

Same anti-pattern ADR-075 removed from `/admin/org-kpi-data`.

## Decision

Remove the debounced autosave from `useDebouncedResponseDraft`. Keep:
- `setDraft` sets `status='pending'` (drives an amber "Unsaved changes" pill).
- `flush()` persists immediately (called by the Save draft button, Submit, and
  Send back).
- Unmount cleanup calls `persist()` if `status === 'pending'` so a route-away
  doesn't drop the last edit.
- `useUnsavedChanges(status === 'pending')` shows the browser `beforeunload`
  prompt while there are dirty edits.

## Consequences

- Writes are now single-path (explicit) — no race between debounce and button.
- Users who relied on "close the tab and it saves" now see the Unsaved pill
  and the browser leave-warning; the on-unmount `persist()` covers in-app
  navigation.
- No schema / RLS / service change.

## Rollback

Restore the `setTimeout(persist, delay)` block in `setDraft` and drop the
`useUnsavedChanges` call. Fully additive; no data migration.
