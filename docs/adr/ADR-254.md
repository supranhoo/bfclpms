# ADR-254 — TNI report source-of-truth shift & complete paging

## Status
Accepted — 2026-08-11

## Problem
Apr–Jun 2026 at threshold 2 / minimum 3 scored months rendered an empty TNI
report, although `tni_qualified_kpis` returned 252 qualifying (employee, KPI)
identities for exactly that range.

## Root cause (verified against live data)
1. **Source-of-truth mismatch.** The report listed only persisted
   `training_needs` detection rows and used the RPC purely as a filter.
   Detection is run on demand at whatever threshold was configured that day, so
   lowering the threshold today creates no records — 30 of the 252 qualifying
   identities had no stored row and were therefore invisible.
2. **Silent 1,000-row truncation.** `useTrainingNeeds` was unpaginated and hit
   the PostgREST cap. The range holds 2,290 rows, so whole months were dropped
   by priority/creation order, losing further qualifying identities.

## Decision
- `tni_qualified_kpis` is the report's source of truth. `mergeQualifiedWithNeeds`
  builds one display row per qualifying identity; persisted rows only enrich it
  (priority, status, gap type, recommendation) and can never gate it.
- Unactioned rows default to `priority = high`, `status = identified`, with the
  worst in-range score, and are counted in the rule banner separately.
- Employee identity for unactioned rows resolves through `useTniEmployeeProfiles`
  (chunked `in` lookups) rather than the persisted row's join.
- `useTrainingNeeds` pages to completion in 1,000-row batches.
- Fetch failures surface as a destructive alert instead of an empty report.
- Export gains a `Detection Record` (Yes/No) column.

## Consequences
Row counts rise to match the qualification RPC; the report can no longer show
zero while the rule qualifies employees. Rollback: restore `filterQualifiedNeeds`
in `TNIReport.tsx` and the unpaged query.

## Tests
`src/test/tni/mergeQualified.test.ts`, plus the existing continuity, range-stamp,
month-column and minimum-window suites.

## Superseded security note
The source-of-truth decision remains active. ADR-255 supersedes only the RPC
security model and the misleading “Backfill” UI terminology.
