# ADR-351 — Org KPI Data Entry renders structured KPI text (not raw `kpi_name`)

Date: 2026-09-03 · Status: Accepted

## Context

A KPI updated from the Performance Console ("Achieve 1050 TPD Power Generation target")
still displayed its old pasted wording on **Admin → Org KPI Data Entry**. Users read this
as "the console update did not apply".

Verified in the database: every month from Apr-2026 onward carries the structured columns
(`kpi_title`, `kpi_description`, `kpi_formula`, `kpi_scoring_logic`) written by the console
on 01–02 Sep 2026. The legacy `kpi_name` still holds the original blob — by design, it is
the join key for history, reports and Org KPI matching and is never rewritten by the
console (ADR-334 / ADR-337).

## Root cause (5 Whys)

1. The card printed `data.kpiName` verbatim (`OrgKpiEntryCard.tsx`).
2. The card predates the ADR-269b structured text split and was never migrated.
3. Migrating it alone would have rendered blanks: `get_org_kpi_data_entry_snapshot`
   selected an explicit column list that omitted the four structured columns.
4. The ADR-269b rollout covered scorecard/review surfaces; Org KPI Data Entry was not on
   the audit list.
5. No test asserted that a structured KPI renders its title on every KPI-showing surface.

## Decision

- `get_org_kpi_data_entry_snapshot` now selects `kpi_title`, `kpi_description`,
  `kpi_formula`, `kpi_scoring_logic` in its `base`/`rep` CTEs so the `kpi` payload carries
  them. Read-only, additive; no schema, RLS, grant or key change. Grouping stays on
  `category_id + kra_name + kpi_name`.
- `OrgKpiEntryCard` renders `<KpiTitle legacyFullText>` + `<KpiTextBlocks collapsible
  hideLegacy>` instead of the raw name. Legacy rows (no `kpi_title`) render exactly as
  before — the full `kpi_name` text, nothing else.
- `OrgKpiCardData` gains four optional display-only fields, plumbed from the snapshot in
  `OrgKpiDataEntry.tsx`. All matching, propagation and lookup keys keep using `kpi_name`.

## Consequences

- Structured KPIs show a one-line title with labelled Description / Formula / Scoring Logic
  blocks (secondary blocks collapsed on mobile).
- Correcting the *stored* legacy name remains the explicit, reversible
  `correct_kpis_range` operation in KPI Standardization.

Rollback: revert the component change; the extra RPC columns are inert.

Tests: `src/test/orgKpiStructuredText.test.ts` (4); Org KPI suites 197 pass.
