# ADR-089 — Orphan Incident Revival

Date: 2026-06-11
Status: Accepted
Phase: Safety migration plan — Phase 1

## Context
The Safety incident FSM (`safety_incidents.status`) is enforced by:
- `transition_safety_incident()` — the only public path that may move status forward, blocks `orphaned → *` and `closed → *`.
- `safety_incident_fsm_guard` BEFORE UPDATE trigger — rejects any direct status mutation outside the RPC.

An incident can become `orphaned` when its owner is deactivated or removed from `safety_user_roles`. Before this ADR there was no UI or RPC to bring an orphaned incident back into the workflow — an admin had to manually edit DB rows, which the trigger blocked.

## Decision
Add a dedicated SECURITY DEFINER RPC `revive_orphaned_safety_incident(p_incident_id, p_assigned_to, p_notes)` that:
1. Verifies the caller has `admin` or `safety_head` safety role.
2. Validates the target assignee is an active profile.
3. Sets a session-local bypass flag (`app.safety_fsm_bypass = 'orphan_revival'`) honoured by the FSM guard.
4. Moves the incident `orphaned → assigned`, stamps `assigned_to` / `assigned_at`.
5. Writes a `safety_incident_timeline` row with `from_status='orphaned'`, `to_status='assigned'`, `changed_by=auth.uid()`.

The session flag approach keeps the FSM guard as SSOT for stage rules — no general "skip the guard" door is opened.

## UI
- `OrphanIncidentDialog` (new) — assignee picker + notes, gated by `useMySafetyRoles`.
- `SafetyIncidents` list — clicking an `orphaned` row opens the dialog instead of navigating to detail.
- `SafetyIncidentDetail` — banner + "Revive & Reassign" button for orphaned incidents.

## Alternatives considered
- **Relax `validateFsmTransition` to allow `orphaned → reported`** — rejected. Would weaken the client-side FSM mirror.
- **Reuse `transition_safety_incident` with a special flag** — rejected. Keeps the canonical sequential RPC focused.

## Rollback
- `DROP FUNCTION public.revive_orphaned_safety_incident(uuid, uuid, text);`
- Revert `safety_incident_fsm_guard` to the version without the `v_bypass` branch.
- Remove `OrphanIncidentDialog` and its imports; restore previous `onClick` handlers.

## Audit trail
Every revival inserts one timeline row attributable to the actor.
