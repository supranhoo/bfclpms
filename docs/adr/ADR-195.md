# ADR-195: Bulk Review multi-select filter parity (org axes)

- Status: Accepted (July 2026)

## Context
`BulkReviewDashboard` exposes multi-select filters for Company / Division / Business Unit / Department, but `bulk_scope_preview` and `bulk_review_snapshot` accept only one value per axis. The page collapsed the arrays with `oneOrNull()` — sending `null` for 2+ selections, which returns the FULL scope. Client-side compensating filters existed for KRA, Category, Designation, Grade and Reporting Manager, but NOT for the org axes.

Reported case: with Divisions = [DRI, SMS], Anil Kumar Pathak (200301, CLU-Operation → CLU → **Ferro**) and Babloo Kumar Shah (101209, 45 MW-Operation → 45 MW → **CPP**) still rendered.

This is the third occurrence of the same class of defect (KRA in v2.66.12.5, Category later, org axes now).

## Decision
1. `rpc_bulk_employee_attrs` additionally returns `company_id`, `department_id`, `business_unit_id`, `division_id` (BU/division derived via `departments → business_units → divisions`). Read-only, SECURITY DEFINER, same signature.
2. New pure helpers `allowedOrgEmployeeIds()` / `hasOrgFilter()` in `src/lib/bulkEmployeeFilter.ts` — AND across axes, OR within an axis; employees with a NULL attribute are excluded when that axis is active.
3. `loadedRows` in `BulkReviewDashboard.tsx` applies the org filter for ANY selection count. Single-value selections keep the server fast path; the client filter is then a no-op.
4. Fail-closed while `useBulkEmployeeAttrs` is loading/errored and an org filter is active.
5. Pre-load preview counters are prefixed `~` and tooltipped as approximate when any axis has 2+ values.
6. Generalised as POLICY §UI-MULTISELECT-SERVER-PARITY.

## Consequences
- Org filters now narrow correctly at any selection count; header chips (emp/KPI/cells) derive from loaded rows and self-correct.
- Employees with no department mapping disappear when a Division/BU/Dept filter is active — intentional and test-locked.
- Rollback: revert the client patch; the additional RPC columns are inert.
- Regression: `src/lib/bulkOrgFilter.test.ts` (8 assertions, includes the exact reported case).
