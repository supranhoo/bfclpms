# ADR-357 — Declutter the reviewer KPI card list (tablet / mobile)

Status: Accepted (2026-09-03)

## Context
After ADR-356, the reviewer card list at 834px (iPad portrait) rendered two
columns of ~380px cards. Users reported the result felt *more* cluttered: dense
badge headers, KRA eyebrow lines repeating the KPI title word-for-word, a
two-badge Org KPI row inflating card height, a ragged unequal-height grid, and
the scorecard toolbar (Add KRA / Copy KRAs / Zero-Score / Rollover KRAs)
overflowing the right edge of the viewport.

## Decision
Presentation-only follow-up to ADR-356. No props, permissions, workflow,
scoring, RPC, RLS or schema changes.

1. **Grid breakpoint raised.** `UnifiedScorecard` card list moved from
   `md:grid-cols-2` to `lg:grid-cols-2` — single column below 1024px, two
   columns only where cards keep comfortable width.
2. **KRA eyebrow de-duplication.** `kraDuplicatesTitle` (pure display
   predicate, normalised prefix comparison, first 40 chars) suppresses the KRA
   eyebrow line when it repeats the resolved KPI title. Data untouched.
3. **Header cluster collapsed.** The org-scope tooltip icon was removed from
   the header; scope information lives in the org info line (item 4).
   Frequency badge, Sent-Back badge and observation count remain.
4. **Org KPI row merged.** The two pill badges ("Org KPI" + "Data Owner /
   Entered by") are now one muted 12px line: `Org KPI · Entered by <name>`.
5. **Toolbar overflow fixed.** The scorecard action toolbar wraps
   (`flex-wrap`) so it can never extend past the viewport edge.

## What stays from ADR-356
Single canonical status badge in the header; labelled View/Review/Send-back
controls with >=44px hit areas (ADR-355); tabular metric grid with `n / 5`
score context; semantic tokens only.

## Consequences
- iPad portrait (834px): one card per row, shorter cards, no repeated text,
  fully visible toolbar.
- >=1024px: two-column grid retained.
- Mobile: unchanged single column with the same de-duplication applied.

## Rollback
Revert `MobileKpiCard.tsx` and the two `UnifiedScorecard.tsx` hunks. No data
involved.

## Tests
`src/tests/mobileKpiCardPresentation.test.ts` extended (eyebrow suppression,
no header tooltip, single org line, `lg` grid, toolbar wrap) —
21/21 green together with `reviewerReopenAffordance.test.tsx`.
