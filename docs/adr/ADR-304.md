# ADR-304 — Assign New KRA: full-page surface and collapsible legacy KPI text

**Status:** Accepted · **Date:** 2026-08-21
**Relates to:** ADR-269b, ADR-272

## Context
"Assign New KRA" (`AdminKpiCreateDialog`) ran inside a `max-w-4xl` modal with a
fixed `h-[72vh]` `ScrollArea`. On a full desktop the form was squeezed into a
narrow, two-column scroller. The legacy free-text KPI name box — kept only for
rows that predate the ADR-269b text split — occupied the top of the definition
block on every new KPI, where it is almost never used.

## Decision
Presentation only, no change to form state, validation, payload builders
(`buildTextPayload` / `buildScoringPayload`) or the `useCreateKpi` write path.

1. **Wide contained surface.** `DialogContent` is
   `w-[96vw] max-w-[1200px] max-h-[92vh] overflow-hidden` with a sticky
   header, a `flex-1 min-w-0 overflow-y-auto overflow-x-hidden` body and a
   sticky footer holding Cancel / Assign KRA.
   *Amendment (2026-08-21):* the first cut used `w-screen h-screen`. Because
   `100vw` includes the scrollbar and the dialog is centred by transform, the
   panel was wider than the usable viewport and produced a horizontal
   scrollbar. Grid children also lacked `min-w-0`, so long inputs pushed the
   layout wider. Both are fixed: the dialog is viewport-contained and every
   grid column carries `min-w-0`.
2. **Structured sections.** The body is three bordered cards: *Assignment*
   (KRA library search + employee), *KRA Identity* (category, KRA, KPI,
   structured text, numeric scoring, effective period) and
   *Metrics & Configuration* (UOM type, numeric/binary/tiered blocks with their
   scoring editors, advanced switches). Columns split at `lg`.
   Every control, tooltip and badge that existed before is retained.
3. **Collapsible legacy text.** In `KpiTextSplitFields`, "KPI Name (legacy free
   text)" is a `Collapsible`: collapsed by default with a one-line preview of
   its content, auto-opened when the row carries legacy text and no structured
   title. The `disabled`-when-structured rule is unchanged.

## Consequences
- All three entry points (Dashboard self/reviewer view, Admin → All KPIs, KRA
  Issuance confirm dialog) keep their existing props and behaviour.
- The Admin KPI Editor shares `KpiTextSplitFields`, so it inherits the
  collapsed legacy box.
- Regression cover: `src/test/kpiTextDisplay.test.tsx`,
  `src/test/kpiTextSplit.test.ts`.

## Rollback
Revert `AdminKpiCreateDialog.tsx` and `kpi-form/KpiTextSplitFields.tsx`; there
is no schema, RPC or policy dependency.
