# ADR-246 — Development Report auto-capture delivery

## Date
2026-08-04

## Status
Accepted

## Context
The Development Report (`/reports/dev-report`, POLICY §131) stalled at
2026-06-15. Capture logic lived only in a local script with no trigger, so the
report silently drifted ~2 months behind the repo.

## Decision
Capture is delivered by the application, not by a human running a script:
a single SSOT parser (`src/lib/devReport/capture.ts`) is executed at build time
by a Vite plugin, bundled as `virtual:dev-report-capture`, and pushed by admins
through the idempotent `dev-report-ingest` edge function in batches of 100.
Staleness (>14 days behind the newest artefact) is surfaced in the UI.

## Consequences
- Report can never silently stall without a visible banner.
- Reseed script and app share one parser; drift is impossible.
- Client bundle carries parsed rows only, never raw migrations.
