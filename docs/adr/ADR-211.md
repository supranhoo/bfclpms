# ADR-211: A saved self-review draft implies `pending_self`

## Status
**Accepted**

## Date
2026-07-31

## Context
Employee 102014 (Kumar Ambarish) showed as **Not Started** in the annual review
admin grid, yet `annual_review_responses` already held a `self` row with five
criteria scores and qualitative answers (`is_locked = false`,
`submitted_at = NULL`). The instance `b5428dbe…` sat at
`overall_status = 'not_started'` with `enabled_stages = [self, dept_head,
bu_head]`.

Root cause: `upsertResponseDraft()` in
`src/services/annualReview/annualReviewService.ts` writes the draft row but
never touches `annual_review_instances.overall_status`. Status only advances at
*submission* time via `advance_annual_review_status`. An instance therefore
stays at `not_started` for the whole drafting window, which renders as a grey
"Not Started" chip and keeps the review out of every pending queue — it looks
abandoned even though work has been saved.

Only one such instance existed in cycle `b82a935f…` (2078 completed, 492
excluded, 7 `pending_bu`, 1 `pending_dept`, 1 `pending_self`), so the exposure
was small, but the gap is structural, not a one-off.

## Decision
1. A self response row existing for an instance means self review has **begun**.
   `not_started` is therefore an invalid status for such an instance.
2. Enforced server-side by `trg_ar_draft_implies_pending_self` (AFTER INSERT OR
   UPDATE on `annual_review_responses`), which bumps `not_started →
   pending_self` for `reviewer_role = 'self'` writes. `SECURITY DEFINER` so the
   employee's own draft save can move the status without widening the RLS
   update policy on `annual_review_instances`.
3. The trigger only ever moves `not_started` forward. Any other status is left
   untouched — no rewind path is introduced (ADR-184 invariant preserved).
4. `src/lib/annualReview/draftImpliesPendingSelf.ts` is the client-side mirror
   of the same rule; both definitions must stay in lockstep.
5. The 102014 repair was recorded in the dated audit table
   `annual_review_status_repair_2026_07` with `performed_by = NULL` (system-run
   repair), consistent with ADR-183/185.

## Consequences
- Reviews with saved-but-unsubmitted self answers now appear as **Self Review
  Pending** and surface in pending queues and reminders.
- No schema change to `annual_review_instances`; additive trigger plus one
  audit table.
- Rollback: drop `trg_ar_draft_implies_pending_self` and set the affected
  instance back to `not_started` using the snapshot in
  `annual_review_status_repair_2026_07`.
