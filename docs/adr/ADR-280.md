# ADR-280 — KPI detail opens as a centered wide modal


- **Status:** Accepted
- **Date:** 16 August 2026
- **Related:** ADR-259, ADR-270, ADR-275, ADR-279

## Context
The KPI detail surface was a right-side sheet capped at `sm:max-w-3xl`. The
definition grid, scoring scale and the mapped-employee table were stacked in one
narrow column, so the table scrolled far below the fold and the group actions
scrolled out of reach.

## Decision
Presentation-only: render the KPI detail as a centered `Dialog`
(`w-[96vw] max-w-[1180px] max-h-[92vh]`) with three regions —
a sticky header (title, KRA · period, mapped-count chip), a sticky action bar
(group entry / approve / edit / tune, all `h-10`), and one scrollable body.
The body uses a 7/5 split on `lg+`: metadata + description on the left, scoring
scale on the right. The mapped-employee table is capped at 420px with a sticky
header row and row hover.

## Consequences
- Component renamed in behaviour only; the export `KpiDetailDrawer` and all
  props (`args`, `onPageChange`, `onClose`, `onSelectVariant`) are unchanged, as
  are the nested group dialogs, pagination and RPCs.
- Amber literals replaced with the `warning` token (ADR-279).

## Rollback
Swap `Dialog`/`DialogContent` back to `Sheet`/`SheetContent side="right"`.
