# ADR-234 — Annual review system scores are scoped to the effective template

Date: 2026-08-03 · Status: Accepted · Supersedes nothing · Related: ADR-116, ADR-166, ADR-187, ADR-212, ADR-232

## Context
Employee 200301 showed Self 2.49/5 on screen and ~4.2/5 in the Annual Review Report.
His instance carries a template override with one `carry_kra` slot (weight 100, 49.8 pts),
but `system_scores` retained two slots (35 pts) from the template he was moved off.
`annual_review_compute_final_summary()` summed every key in the JSONB, so the final score
(84.80) and band ("Good") were computed from slots that no longer exist on his form, while
the KRA-derived stage rating used the template pool (49.8 / 100 × 5 = 2.49).
Ten instances in the 2025-26 cycle were affected.

## Decision
1. `annual_review_compute_final_summary()` sums system points only for slot ids declared by
   `COALESCE(template_override_id, template_id)`.
2. Template changes auto-prune orphan keys (`trg_ar_prune_orphan_system_scores`), writing
   each removed key to `annual_review_system_score_edits` (old raw/points/score/rating).
3. Admin-only audited repair `annual_review_prune_orphan_system_scores(cycle, reason, dry_run)`
   and diagnostic `annual_review_orphan_system_scores(cycle)`.
4. Client mirror `src/lib/annualReview/systemScoreScope.ts`; monitor card on the
   Orphaned Reviews admin tab.

## Consequences
- Scores of the 10 repaired instances change; 200301 drops to 49.80 / "Poor" (2.49/5).
- Rollback: audit rows retain the pruned values and prior score/rating.
- Tests: `src/lib/annualReview/systemScoreScope.test.ts`.
