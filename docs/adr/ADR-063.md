# ADR-063 — Surface the silent-zero Propagate guard

- Status: Accepted (May 2026)
- Context: For Per-Employee scope Org KPIs, six employees on "Proactive Safety Reporting" (May 2026) showed `0` in the input cell and a red `0 – Not Achieved` rating chip, but the per-row pill stayed `Not propagated`. Live DB confirmed `org_kpi_values.achieved_value = NULL` for those rows — no value had ever been persisted. The `0` came from local React state (typed/bulk-filled this session) and the page's `handleSaveAndPropagate` then silently skipped them via the v2.65.4 guard `if (!sv._touched && sv.achievedValue === 0 && !sv.isNa) continue;`. The user reasonably reported "but see, data is there" and assumed propagation was broken.
- Decision:
  1. **Reason micro-label.** `RowStatusPill` in `src/components/admin/OrgKpiScopedEntryTable.tsx` accepts an optional `reason` and renders it as a small italic amber chip next to the pill. The row-render site computes one of: `"No value entered"`, `"Unsaved — wait for autosave, then Propagate"`, or `"0 not saved — click cell then Save"`.
  2. **DB-anchored value.** `ScopedRow` gains an optional `dbAchievedValue` (raw `org_kpi_values.achieved_value` at fetch time). `buildCardData` in `OrgKpiDataEntry.tsx` populates it for both the department and employee branches. `OrgKpiEntryCard`'s scoped-row merge effect refreshes it from DB so the "Unsaved" chip clears the moment autosave commits.
  3. **Vocal-not-silent guard.** The silent skip remains (we still refuse to push an unedited `0`, per POLICY §111.7), but it now increments `untouchedZeroSkipCount` and emits a destructive summary toast after the loop telling the user exactly which action to take.
- Consequences:
  - Owners can immediately tell why a row shows a value but the pill says "Not propagated".
  - No DB schema change. The propagation RPC is untouched.
  - The skip behaviour is unchanged for safety; only its visibility improves.
- Tests: existing 6 `orgKpiTileStatusChipParity` cases + 10 `orgKpiEmptyState` cases continue to pass. The new chip/reason path is additive UI and gated on `dbAchievedValue !== achievedValue`.
