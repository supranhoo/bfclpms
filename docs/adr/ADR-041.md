# ADR-041: Incentive Report Export Completeness

## Status
**Accepted**

## Date
2026-03-30

## Context
Incentive report exports were missing disqualification fields, creating gaps in payroll reconciliation and audit trails.

## Decision
All incentive report exports (Excel/XLSX) must include the full set of DQ fields: `Is Disqualified`, `Disqualification Reasons`, and `LTI Penalty %`. The export must produce at least 28 columns covering Employee Info, Period, Programme, Scores, DQ Fields, Adjustments, Final, and Analytical data.

## Alternatives Considered

### Alternative A: Minimal export with only summary fields
- **Description:** Export only employee name, score, and final incentive amount
- **Rejected because:** Incomplete reports risk payroll errors and compliance gaps. DQ data is critical for audit trails and financial reconciliation.

### Alternative B: Separate DQ report
- **Description:** Create a dedicated disqualification report alongside the main incentive report
- **Rejected because:** Forces payroll teams to cross-reference two documents. A unified export is more practical.

## Consequences

### Positive
- Complete audit trail in every export
- Single document for payroll processing

### Negative
- Wider spreadsheet with more columns (acceptable for data completeness)

### Neutral
- Export template structure is enforced programmatically
